Hi,<br/><br/>

This repo explores tools and techniques for cases when:<br/><br/>

change is constant,<br/>
its impact is hard to predict,<br/>
quality is not explicitly defined,<br/>
and intent gets lost in implementation.<br/><br/>

These tools explore ways to make:<br/><br/>

quality models evolve with the system,<br/>
change effects measurable and comparable,<br/>
quality explicit through shared dimensions and hierarchy,<br/>
and ideas traceable end-to-end to production behavior.<br/>
